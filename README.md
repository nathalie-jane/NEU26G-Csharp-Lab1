# Lab 1 - Find Numbers in a String

A console application that searches a string for number segments that:

- Start and end with the same digit
- Contain only digits between the start and end
- Do not contain the starting digit again before the ending digit

Each valid number segment is displayed by printing the full input string and highlighting the matching segment in a different color.
It also converts each valid segment to a number, adds the values together, and displays the total sum at the end.
